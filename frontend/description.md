# frontend/
## src内部での各ディレクトリの責務
### components
- 画面を構成する部品を用意する
- ボタンなどを用意するだけで、組み立ては行わない

### core
- アプリの設定を記述する
- 基本的には.envファイルを読み込み、バックエンドで利用可能にすることが責務
- security.py: パスワードの保存形式などセキュリティについて
- config.py: アプリ全体について

### pages
- コンポーネントを組み合わせて画面を作成する

### hooks
- 関数コンポーネントに状態やライフサイクルを持たせる
- 理解がまだ甘いので今後追記する

### services
- APIリクエストを送信してバックエンドと連携する
- ここでバックエンドの機能を利用する

### types
- TypeScriptの型を定義する
- backend/schemasと基本的には一致する

### App.tsx
- 各ページのルーティングを設定する

### main.tsx
- ブラウザからReactを起動する

## frontend/src/ 以外
- package.json: プロジェクト情報を記載して使用するパッケージやコマンドを定義する
- vite.config.ts: Viteのための設定の記載
