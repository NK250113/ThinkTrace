- ユーザ登録
- ログイン：ユーザIDとパスワードから本人確認
- ユーザ情報取得
- ユーザ情報の変更：フレンドコードみたいなのも変更できるように
- 設定の取得・変更
- タグ取得：必要なタグを取得してファイル検索に利用する
  - 上位のタグを表示：タグを選択する
  - 一致/包含するタグの探索：タグを手入力で検索する
- ノート探索(タグ選択部分)：取得したタグでノートの検索を行う(複数の場合はAND)
- ノート復元(ファイル選択部分)：ノートが選択されたときに最新のコミットを再現する
- コミット：現在のノートの状態を最新のコミットとして保存して、前回のコミットの保存形式を整える
  - 同時に途中更新を呼び出す
- 途中更新：編集中に別ユーザ等によってコミットがされたときその内容の通り更新する
  - ロストアップデートが発生するとき：無視/上書きの２つを準備
- コミット一覧取得：コミットの内容以外の情報を取得する
- コミット一部取得：特定の期間に入るもののみを取得する
- 履歴から変更内容の復元：あくまで変更内容を渡すだけにして、本格的な復元はフロントエンドで
