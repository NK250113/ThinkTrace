## 主な機能(再掲)

- 箇条書き機能
  - 独自の記号を用いた特殊な箇条書き
  - 箇条書きの種類から文脈を判断して自動で階層構造を作成
- 履歴機能
  - 現状と過去を比較して考え方の変遷を可視化
- 同期機能
  - ログインすれば別の機器からでも編集ができる
  - 複数人での閲覧/編集も可能に
- AI機能
  - ヘルプをAIで使いやすく
  - 思考の変遷を全体的に見て分析

## 独自の記号一覧

| 関係  | 記号 | キー | 例 | Enter時の挙動 |
| --- | -- | --- | --------------- | ------------|
| 仮説 | 電球 | Hypothesis | 経済格差は問題でない | まとめを生成、+1rank |
| 疑問 | ハテナ | What | なぜだろうか | まとめを生成、+1rank |
| まとめ | 旗 | Summary | 資本主義は悪ではない | 自身を-1rank |
| 目的 | 的 | Goal | ～をしたい | 手法を生成、+1rank |
| 手法 | スパナ | Method | そのために～をする | 手法を生成 |
| 重要 | 煌めき | !(important) | 更なる議論が必要 | なし |
| 列挙 | 小さい丸 | -(list) | 省略(普通の箇条書き) | 列挙を生成 |
| 抽象化 | 雲 | Abstract | 犬・猫 → 哺乳類 | なし |
| 因果 | 歯車 | Cause | 雨が降る → 地面が濡れる | 因果を生成 |
| 根拠 | 錨 | Evidence | データ → 結論 | 根拠を生成 |
| 時系列 | 時計 | Time | 起床 → 朝食 | 時系列を生成 |
| 条件 | 漏斗 | If | 雨なら → 傘 | +1rank |
| 依存 | 鎖 | Dependency | コンパイル → ソースコード | 自身を+1rank |
| 比較 | 天秤 | comPare | Linux ↔ Windows | 比較を生成、+1rank |
| 反論 | 剣 | But | ～という視点もある | なし |
| 参照 | 本 | Reference | URLを貼る | 自身を+1rank |
| 引用 | ❝ | >(quote) | mdの引用と同じ | なし |

### 概要
- 完成後も必要があったら追加していく
- 対応キー(キー列の大文字の部分)+スペースで記号が入力される
- Alt+対応キーでも入力できる
- 入力画面の右に記載して忘れてもすぐ参照できるようにしておく
- Enter時の挙動にあるrank表記は改行先の階層を変化させることを表す
- 比較、例示は特殊な表記にしたい

## 履歴の保存/可視化方法
- メモの各行がいつ追加/削除されたかの履歴を保存
- 履歴は差分保存を行う
- 履歴を見る画面では最新のものから順に履歴一覧を表示していく
  - 表示と同時に少しずつ読み込むことで、少しずつ遡っていく自然な動きをすると読み込み時間が長くならずに済む
- 表示はGitHubのように行ごとに背景色を付けてどのような変化があったのか可視化する
  - 赤色が削除、緑色が追加

## 同期の仕組み
- ログインすれば別の機器からでも編集ができる
- 編集中にロックは行わない
- 編集中にコミットがなされるとそれに合わせてデータ更新をすることができる
- 更新をするか、ロストアップデートが発生する場合はどうするかユーザが決定
- 暫く更新をスキップした後更新を行うとそこまでの更新が全て適応される
- ユーザのアクセス/編集許可を決定して複数人の閲覧/編集を可能に
