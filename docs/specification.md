## 主な機能(再掲)

- 箇条書き機能
  - 独自の記号を用いた特殊な箇条書き
  - 箇条書きの種類から文脈を判断して自動で階層構造を作成
- 履歴機能
  - 現状と過去を比較して考え方の変遷を可視化
- 同期機能
  - ログインすれば別の機器からでも編集ができる
  - 複数人での閲覧/編集も可能に
- AIによる要約・思考の傾向の変化の分析

## 独自の記号一覧

| 関係 | キー | 例 |
| --- | --- | --------------- |
| 仮説 | Hypothesis | 経済格差は問題でない |
| まとめ | Summary | 資本主義は悪ではない |
| 重要 | !(important) | 更なる議論が必要 |
| 列挙 | List | 省略(普通の箇条書き) |
| 包含 | iNclude | 動物 → 犬 |
| 構成 | coMposition | 車 → エンジン |
| 因果 | Cause | 雨が降る → 地面が濡れる |
| 根拠 | Evidence | データ → 結論 |
| 時系列 | Time | 起床 → 朝食 |
| 条件 | If | 雨なら → 傘 |
| 依存 | Dependency | コンパイル → ソースコード |
| 比較 | comPare | Linux ↔ Windows |
| 例示 | eXample | 果物 → リンゴ |
| 抽象化 | Abstract | 犬・猫 → 哺乳類 |

- 完成後も必要があったら追加していく
- 対応キー(キー列の大文字の部分)+スペースで記号が入力される
- Alt+対応キーでも入力できる
- 入力画面の右に記載して忘れてもすぐ参照できるようにしておく

## 履歴の保存/可視化方法
- メモの各行がいつ追加/削除されたかの履歴を保存
- 履歴は差分保存を行う
- 履歴を見る画面では最新のものから順に履歴一覧を表示していく
  - 表示と同時に少しずつ読み込むことで、少しずつ遡っていく自然な動きをすると読み込み時間が長くならずに済む
- 表示はGitHubのように行ごとに背景色を付けてどのような変化があったのか可視化する
  - 赤色が削除、緑色が追加

## 同期の仕組み
- ログインすれば別の機器からでも編集ができる
- 編集中にロックは行わない
- 編集中にコミットがなされるとそれに合わせてデータ更新をすることができる
- 更新をするか、ロストアップデートが発生する場合はどうするかユーザが決定
- 暫く更新をスキップした後更新を行うとそこまでの更新が全て適応される
- ユーザのアクセス/編集許可を決定して複数人の閲覧/編集を可能に
