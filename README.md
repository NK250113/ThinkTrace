# ThinkTrace

## 概要
何を作ったか
- 思考のサポート・蓄積・整理を行うメモアプリ

## 特徴
- 箇条書きの書きやすさと「しかし」「なので」といった論理構造を両立する独自の書き方
- GitHubのような履歴を残すことによる過去の思考からの変遷を記録

## 背景
- よく思考したことを忘れる
- これまでObsidianを使っていたが不満があった
  - 箇条書きでは脳内で組んだ論理構造を表現できない
  - 過去のメモとの繋がり方が薄い
    - GitHubのように過去と比較ができたら便利なのでは
  - 見やすさ・文章としての質が気になるせいで思考に集中できない

そこで，
- 思考中は見た目を気にせず高速に書ける
- 論理構造をそのまま表現できる
- 思考の変遷も残せる

そんなメモアプリを目指して開発を行った．

## 実行方法
- [ここをクリック](https://github.com/NK250113/) (本サービスにアクセスできます)

- Dockerを起動して以下のコマンドを実行
  ``` bash
  docker run ThinkTrace
  ```

## 主な機能
- 箇条書き機能
  - 独自の記号を用いた特殊な箇条書き
  - 箇条書きの種類から文脈を判断して自動で階層構造を作成
- 履歴機能
  - 現状と過去を比較して考え方の変遷を可視化
- 同期機能
  - ログインすれば別の機器からでも編集ができる
  - 複数人の閲覧/編集も可能に
- AIによる要約・思考の傾向の変化の分析
